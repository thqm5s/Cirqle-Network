# CIRQLE

**A web design and coding experiment.**

CIRQLE is one of my first experiments in website creation. It is a concept for a private networking platform, designed as a way to explore web development, improve my coding skills and experiment with AI-assisted development (*vibe coding*).

## About the Project

The idea was to create a website mockup for a private networking platform where users could apply to join a community and connect with other members.

The project was primarily an opportunity to practice building a website from scratch, experiment with different layouts and learn more about the overall development process.

## Design

I wanted to create a minimalist and modern interface, with a strong focus on simplicity and visual consistency.

The design features:

* **Minimalist aesthetics:** A clean layout with plenty of whitespace and a neutral color palette.
* **Liquid Glass:** Subtle glass-like effects, soft shadows, blurred backgrounds and translucent elements.
* **Bold Typography:** Large, geometric typography to give the website a distinctive visual identity.
* **Smooth Layout:** A structured, responsive interface with different sections throughout the page.

The homepage shown in the preview is only the beginning of the design. The full mockup includes additional sections and content further down the page.

## Goals

The main purpose of this project was to:

* Improve my web development and programming skills.
* Experiment with vibe coding and AI-assisted development.
* Learn how to structure and build a website.
* Explore UI/UX design, typography and visual identity.
* Practice turning an idea into a complete website mockup.

## Project Status

**Prototype — Not Deployed**

CIRQLE was created as a learning experiment and has never been publicly launched. It remains a website mockup rather than a fully functional platform.

## Tech & Development

The project was an opportunity to experiment with web technologies, coding workflows and AI-assisted tools as part of my learning process.
